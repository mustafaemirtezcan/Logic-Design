# 🧑‍💻Logic Design

Verilog circuits, each with its own testbench. Every folder has the assignment PDF and the source files.

- **A1 - Combinational Circuits:** full adder, 4-bit ripple-carry adder, adder/subtractor, 2x1 mux and two's complement.
- **A2 - Sequential Circuits:** D and JK flip-flops, and the same state machine built with each.
- **Final - LLM-42:** a state machine that reacts to green, red and yellow signals with a timer. The `.gtkw` files open the scenario waveforms in GTKWave.
