# Logic Design

Verilog modules with testbenches. Each folder contains the assignment description and the source files.

- **Combinational Circuits:** Full adder, 4-bit ripple-carry adder, adder/subtractor, multiplexer and two's complement.
- **Sequential Circuits:** D and JK flip-flops and state machines built with them.
- **LLM-42:** Timer-driven state machine, with GTKWave files for each test scenario.
