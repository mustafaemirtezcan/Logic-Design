# 🧑‍💻 Logic Design

Digital circuits 🔌 written in Verilog and tested in simulation.

- ➕ **Combinational Circuits:** Adders, subtractors and multiplexers built up from basic gates.
- 🔁 **Sequential Circuits:** Flip-flops and the state machines built on them.
- 🤖 **LLM-42:** The final project, a state machine that reacts to signals and timers, with waveforms for every scenario.

📂 Each folder includes the assignment description, the circuits and their testbenches.
