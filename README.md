# 🧑‍💻Logic Design

Digital circuits in Verilog, each with its own testbench. Every folder has the assignment description and the source files.

- **Combinational Circuits:** Full adder, 4-bit ripple-carry adder, adder/subtractor, 2x1 multiplexer and two's complement.
- **Sequential Circuits:** D and JK flip-flops, and the same state machine built with each.
- **LLM-42:** A timer-driven state machine that reacts to green, red and yellow signals, with GTKWave waveforms for every test scenario.
